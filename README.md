# Main_Project (project branch)

A clean and organized Python-based web application named Employee Management System, featuring user authentication, database integration, templates, testing, and container deployment.

##  Key Features

- **User Authentication**: Secure login, registration, and session management via `auth.py`.
- **Database Handling**: Robust connection and session logic in `database.py`; structured schema via `models.py` and `schemas.py`.
- **Database Setup Utility**: `setup_db.py` allows easy initialization and seeding of the database.
- **Web Application Routing**: Defined in `main.py`, orchestrates HTTP endpoints and app behavior.
- **Testing**: `test_app.py` ensures core functionality remains reliable.
- **Containerization**: `Dockerfile` enables consistent deployment environments.
- **Clean Separation of Concerns**: Organized templates and static folders for frontend assets.
- **Version Control Hygiene**: A proper `.gitignore` to streamline repo management.
